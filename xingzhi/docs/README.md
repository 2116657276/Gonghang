# 行止文档中心

更新日期：2026-09-15。状态：B-Ⅰ（阶段 0、B00—B02）接口独立开发已完成，001—023 已进入当前代码基线和本地数据库；B01 真实项目写入、B02 预算草稿的 A03 逐日评估及新消费者 Agent 运行接入等待联合验证，B03—B07 尚未实施，M1 通过前不改前端。

产品范围以 PRD 为准，金额和权限原则以领域规则为准。当前后端月度模型、目标接口和 A/B 分工唯一依据为 [A/B 后端总方案](../行止_AB后端开发总方案_现状接口数据库任务.md)；[开发计划](03-engineering/development-plan.md)维护 M1—M3 大阶段与恢复入口，N 案例由 Demo 文档维护，实际证据由验证策略记录。接口与数据旧正文仅供历史交易及早期设计参考，不能覆盖 A/B 新契约。

行止是拟嵌入银行 App 的青年消费规划微应用：生活目标驱动交互，轻量记账提供事实，近期规划解释可行性和资金影响，登记商品方案比较与选购落实需求，计划改变后按授权调整订单并核验结果，最后用事实做轻量复盘。首版以测试银行数据和登记商品形成受控原型，日常使用模拟支付，最终演示以支付宝沙箱验证交易；不声称真实银行接入。
