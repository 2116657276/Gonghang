# ADR：采用 Pi 单 Agent 核心

| 字段 | 内容 |
| --- | --- |
| 文档编号 | XZ-ADR-01 |
| 日期 | 2026-09-05 |
| 状态 | 核心选择已由用户确认；发行版本待验证 |

## 一、背景

行止需要 TS 优先的单 Agent 多工具循环，支持自然语言购买和计划变更；交易任务需要授权、幂等与异步核验。当前只建设文档。

## 二、决定与候选

采用 Pi agent-core 作为可嵌入核心，自己定义业务工具和运行控制，不直接搬用完整编程助手。LangGraph 可支持单 Agent 与持久化编排，但目前不需要额外一层图管理；Hermes 和 Codex 作为完整助手的扩展候选不进入首版内核；完全手写循环会增加流式、工具和错误处理维护成本。

这些是本项目工程取舍，不是基准测试排名。Pi 不自动解决支付一致性、商户权限和退款恢复，必须由业务后端落实。

## 三、收益、代价与重评条件

收益是保持工具和产品结构可控，复用 Agent 基础循环。代价是自行管理确认、后台任务、会话恢复和观察记录。只读并行、写入受控，Pi 停止不被解释为撤销资金交易。

如选定发行版无法满足必要事件／中断语义，或人工审核分支显著增多，则记录证据并重评；不静默叠加第二个框架。变更需要同步需求、运行设计和测试，不因更换模型自动重开架构。
