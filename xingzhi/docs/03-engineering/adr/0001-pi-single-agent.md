## 一、背景

行止需要 TS 优先的单 Agent 多工具循环，支持自然语言购买和计划变更；交易任务需要授权、幂等与异步核验。S1 已完成不依赖 Pi 的本地业务底座；Pi 运行层已接入只读和方案工具，交易执行仍按 S4 的后续门槛推进。

## 二、决定与候选

采用 `@earendil-works/pi-agent-core@0.85.1` 作为可嵌入核心，配套 `@earendil-works/pi-ai@0.85.1`，通过 DeepSeek 的 `deepseek-v4-flash` 提供模型服务。自己定义业务工具和运行控制，不直接搬用完整编程助手。LangGraph 可支持单 Agent 与持久化编排，但目前不需要额外一层图管理；完整编程助手 CLI 不进入首版内核；完全手写循环会增加流式、工具和错误处理维护成本。

这些是本项目工程取舍，不是基准测试排名，也不是对模型效果或价格的承诺。Pi 不自动解决支付一致性、商户权限和退款恢复，且上游不提供内置的文件、进程、网络和凭据权限边界；首版只注册本项目的 T01—T10 工具，由业务后端落实全部权限和资金约束。

## 三、收益、代价与重评条件

收益是保持工具和产品结构可控，复用 Agent 基础循环。代价是自行管理确认、后台任务、会话恢复和观察记录。只读并行、写入受控，Pi 停止不被解释为撤销资金交易。

项目模型费用累计上限固定为人民币 100 元；Agent 运行采用服务端令牌桶限流、同计划单运行和上游 429 退避。若 `0.85.1` 无法满足必要事件／中断语义，或 DeepSeek 工具调用兼容性无法通过本地烟测，则记录证据并重评；不静默叠加第二个框架。变更需要同步需求、运行设计和测试，不因更换模型自动重开架构。
