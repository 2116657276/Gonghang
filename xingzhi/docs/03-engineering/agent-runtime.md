# 行止 Agent 设计

更新日期：2026-09-15。状态：现有 Pi 运行层复用，新资金与选购流程待实现。

## 一、职责

沿用锁文件中的 Pi 单 Agent 与现有 DeepSeek 配置，不因文档迁移升级依赖。模型负责理解、澄清和解释，确定性服务负责金额、日期、价格、权限和状态。只开放本项目受控业务工具，不加载 shell、任意 HTTP、文件读写、银行凭据或商户直接退款工具。

## 二、现有能力与新增需求

| 能力 | 当前基础 | 迁移要求 |
| --- | --- | --- |
| 目录读取 | `search_catalog` 当前读有效目录，不是成熟条件搜索 | 扩展少量结构化筛选，返回价格、使用和取消条件；无结果如实解释 |
| 计划与订单 | 现有计划内快照工具 | 用户提出需求后先创建消费草稿，再按需读取账户可见范围；不得为聊天创建交易 |
| 购买／变更方案 | 现有草稿工具与确认卡片 | 附近期资金影响，选择替换使旧草稿失效 |
| 交易执行 | 建单、付款交接、暂停、提交已确认变更、状态读取 | 原工具与权限保留，不能把资金告警当取消授权 |
| 账目与规划 | 无完整实现 | 新只读资金／还款／规划工具；记录或修改用户安排采用明确字段和独立保存入口；工具名称及接口按 M1 契约落实 |

不把目录工具旧设计中的“类别、日期约束”视为已经实现；当前空状态入口和资金工具均待开发。具体 API 以[接口契约](api-contract.md)区分已实现与拟新增。

## 三、确认和恢复

Agent 写入权限按行为影响固定如下：

| 行为 | Agent 权限 | 用户确认方式 |
| --- | --- | --- |
| 保存非执行目标草稿 | 可以，但仅限用户当前消息明确表达的目标名称、日期、初始目标预算和需求条件，不推断缺失金额或改变保留目标 | 用户原消息即为保存草稿的明确来源，不逐字段二次确认 |
| 读取规划、检索目录、解释候选 | 可以，只读使用服务端事实并生成待选择建议 | 无需交易确认 |
| 修改 active 目标、目标预算、必须项或可调整项 | 不可直接写入，只能提出修改建议 | 用户在结构化界面确认后由消费者会话写入 |
| 选定或替换商品 | 不可调用 selections 接口 | 用户在结构化界面单独确认商品集合 |
| 确认购买、变更或授权 | 不可调用确认接口 | 用户使用现有确认卡片；商品选择确认不等于购买确认 |
| 修改账户快照、流水金额、执行退款或读取支付凭据 | 始终禁止 | 不向 Agent 开放入口 |

买什么、花多少、允许处理哪些订单最终由用户确认。模型不持有商品选定或交易确认工具。非执行草稿不创建购买授权、订单或支付；计划关联资金规划并进入 active 后，相关目标和商品变化只能走结构化用户确认。资金变化可以触发重新计算和建议，但不能触发自动借贷、还款、取消或新增购买；明确暂停仍可沿用独立按钮和原始用户指令入口。

展示资金、报价和方案依据版本。执行前服务端检查授权、归属、版本、金额及已受理操作；同一业务重复请求复用原操作。不能通过新 Agent 运行号重复建单、退款或预算占用。

用户确认后仅继续对应操作；渠道事件只读取并解释新事实；刷新页面读取持久化快照不调用模型。等待用户或渠道时结束本轮，已受理交易交给 worker。停止推理不等于交易撤销。

## 四、事实解释与费用

金额展示由服务端格式化为元，计算使用整数分。分别解释现金、预计收入、当期还款、待退款、净支出和购买授权空间；引用来源时间，信息缺失时说明范围。沙箱退款不能被解释为银行真实账户到账。

复用现有轮次、超时、共享人民币 100 元费用预算、限流和未知费用预占，不新增自动重试框架。新会话不能清空旧费用，模型失败仍可通过结构化入口查询和处理已确认事项。

新场景在 M1 集中评测，覆盖需求澄清、无合适候选、资金缺口、外部商品文本指令、价格变化及计划调整。历史固定模型记录仅证明原场景；新结果记录在[验证策略](../04-quality/verification.md)。

## 五、生活目标与解释能力

用户可先提出目标，助手在缺少账户或必要支出信息时保留草稿并引导补齐，不能把“尚未关联计划”作为完全无法交互的条件。目标日期、预算和必须／可调整项使用现有计划结构表达，不建长期目标 Agent。

资金规则先返回条件可行性和日期，再由模型解释登记候选取舍。候选比较不创建多个交易草稿；用户选定后进入原独立确认路径。没有两个合格候选时说明缺口，不能编造方案。

用户保存新支出、修改预计收入日期或收到已接入业务事实时，规则先重算；需要解释时产生有界新一轮，方案仍等待用户确认。不常驻模型监控所有账户、不建立新定时服务、不自动执行调整。收入延后可能只改变条件情景，不一定降低已经可用现金，说明中必须区分。

简短决策说明引用事实版本、规则输出、选项差异和授权结果。完成后复盘读取服务端金额派生结果，不输出隐藏推理过程，不自动学习长期偏好。相关检验并入既有新版 N05／N06／N08／N09／N12。
