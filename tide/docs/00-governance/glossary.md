# 潮汐·创证统一术语表

> 文档状态：历史研究分支。术语服务于科创双证据方案，当前潮汐小微借贷周期的术语待另行确认。

| 术语 | 严格定义 | 不应混同 |
| --- | --- | --- |
| 研发里程碑链 | 由立项、验证、检测/认证、试制、知识产权和产品化映射等证据组成的可追溯序列 | 技术先进性评分、科研成果鉴定 |
| 订单兑现链 | 由订单承诺、交付、验收、结算和资金可用状态组成的可追溯序列 | 单纯合同金额、预测收入 |
| 双证据 | 研发里程碑链与订单兑现链相互支持、但独立记录来源和状态 | 将全部材料合并成单一黑箱分数 |
| 候选事实 | 由文档识别或用户录入得到、尚未完成一致性核验的结构化字段 | 已核验事实 |
| 已核验事实 | 已通过规则校验、来源确认或人工复核并记录责任人的事实 | 绝对真实、司法认定 |
| 证据护照 | 记录事实、来源、版本、状态、冲突、复核意见和访问权限的证据包 | 银行审批结论、信用证书 |
| 证据缺口 | 支撑某一里程碑或订单状态所需材料不足、过期或相互冲突 | 自动拒贷原因 |
| 资金时钟 | 从当前时点到订单相关资金预计可用时点的区间表达 | 保证到账日期 |
| 就绪时钟 | 从当前时点到关键证据包达到人工受理条件的区间表达 | 保证获批日期 |
| 双时钟 | 资金时钟与就绪时钟的联合观察 | 两个固定倒计时数字 |
| 保护日 | 由企业授权录入的工资、税费、关键采购等经营约束日期 | 系统替企业作出的经营承诺 |
| 人工复核 | 对冲突、缺失、高风险或机器无法判断的材料进行责任人确认 | 人工自动背书全部真实性 |
| 融资协同 | 帮助企业和客户经理对齐材料、缺口和时间窗口 | 自动授信、撮合放款 |

## 状态词使用规则

活动文档统一使用“待核验、基本一致、存在冲突、材料缺口、待人工复核、已形成证据包”。禁止在未获得外部权威确认时使用“绝对真实、银行认可、已获授信、保证放款、零风险”等表述。
