# 潮汐·创证隐私与安全

> 文档状态：历史研究分支。本文控制措施面向科创双证据资料，当前项目需根据小微借贷周期重新确认数据范围。

## 一、保护对象

企业身份、研发材料、知识产权附件、客户与订单信息、金额、账户信息、复核意见、共享范围和访问日志均属于需要保护的数据。原型不应收集真实账户密码、银行卡号、生产密钥或未获许可的商业秘密。

## 二、控制措施

| 风险 | 控制措施 |
| --- | --- |
| 越权查看研发或订单材料 | 项目隔离、最小权限、短期访问、字段级脱敏 |
| 模型提示注入或恶意附件 | 文件类型校验、内容隔离、模型输出仅作候选、规则层拒绝指令执行 |
| 候选事实被当成真实事实 | 状态分层、来源定位、人工复核、界面固定声明 |
| 复核记录被篡改 | 追加式审计事件、版本快照、变更理由 |
| 护照被超范围传播 | 接收方与用途绑定、有效期、可撤销链接、水印和访问日志 |
| 过度留存 | 数据分类、期限策略、删除流程、最小化日志 |

## 三、人工与模型边界

模型不得独立改变事实核验状态、删除冲突、判断专利价值、决定授信、计算额度或选择材料接收方。高影响操作由有权限的人确认，并保留操作者、依据和时间。

## 四、原型声明

演示数据必须为模拟数据或经授权脱敏数据。项目不得宣称已接入工商银行、征信平台、企业生产系统或真实支付网络；不得保证融资、审批、回款或经营结果。
