# 潮汐历史研究资料索引

| 字段 | 内容 |
| --- | --- |
| 当前项目方向 | 原版小微企业借贷周期，不限定科创 |
| 本目录内容 | 科创小微企业双证据融资协同研究分支 |
| 文档状态 | 历史研究资料，不是当前实施基线 |
| 详细方案 | [科创双证据竞赛方案](01-contest/competition-solution.md) |

潮汐当前关注小微企业经营回款、到期还款与融资准备之间的时间错配。当前方向尚未形成新的完整产品、领域和工程基线，因此本目录暂时保留已完成的科创双证据研究，供借鉴证据组织、时间窗口、人工复核和数据保护方法。

目录内出现的研发里程碑、知识产权、证据护照和“双时钟”等内容，均属于科创研究分支。它们不能直接解释为当前潮汐已经确定的业务对象，也不能替代后续围绕小微借贷周期的重新分析。

## 二、使用边界

- 本目录的详细文档都是设计或研究材料，不代表已上线、真实接入或产生业务效果。
- 公开资料、模拟数据、授权脱敏事实和匿名访谈必须分别标注；没有测试记录的数字不得写成效果结论。
- 术语和决策仅对本研究分支有效。潮汐改回小微借贷周期后，新的范围、案例和规则应建立新的决策记录，不直接覆盖旧研究。
