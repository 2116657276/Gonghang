# 潮汐·创证用户流程

> 文档状态：历史研究分支。本文流程只适用于科创双证据研究案例，不代表当前潮汐流程已经确定。

## 一、主流程

| 步骤 | 企业侧动作 | 系统动作 | 客户经理/复核侧动作 | 输出 |
| --- | --- | --- | --- | --- |
| 1. 建立项目 | 确认主体、产品和授权范围 | 建立隔离材料空间 | 暂无 | 项目与授权记录 |
| 2. 提交材料 | 上传研发与订单材料 | 分类、去重、提取候选事实 | 暂无 | 候选事实清单 |
| 3. 构建双链 | 确认产品、订单映射 | 建立节点关系并执行一致性检查 | 暂无 | 双证据地图 |
| 4. 处理异常 | 补材料或提交说明 | 定位冲突、缺口和时序异常 | 接受、退回或要求补充 | 可审计复核记录 |
| 5. 计算双时钟 | 录入保护日及其类型 | 计算资金与就绪区间 | 查看依据，不将其视为审批预测 | 窗口压力与待办 |
| 6. 生成护照 | 选择共享范围 | 脱敏并生成版本化证据包 | 按制度继续尽调 | 证据护照及未解决事项 |

## 二、候选事实核验流程

`材料上传 → 字段抽取 → 来源定位 → 规则校验 → 候选/冲突 → 人工复核 → 已核验或退回`

任何无法定位来源的字段均不得进入已核验状态。人工纠正不能删除机器原值和历史版本。

## 三、双时钟更新流程

`订单或材料状态变化 → 校验来源 → 更新相应区间 → 与保护日比较 → 生成压力提示 → 记录重算原因`

若只有口头预计而没有可记录依据，系统允许备注，但时钟状态必须显示“依据不足”，不能用备注替代证据。

## 四、共享与撤回流程

1. 企业选择接收方、字段范围、有效期和用途。
2. 系统生成脱敏快照与访问记录。
3. 企业可停止后续共享或撤销未使用链接。
4. 已发生的访问和复核记录继续保留审计痕迹，但不得超出原授权目的再次使用。

## 五、失败恢复流程

| 失败 | 恢复方式 | 用户可见状态 |
| --- | --- | --- |
| 抽取服务失败 | 保留附件并允许人工录入 | 抽取失败，材料未丢失 |
| 规则服务超时 | 不更新核验状态，排队重试 | 校验处理中 |
| 重复上传 | 基于内容标识提示重复，用户选择保留版本 | 重复材料待确认 |
| 复核意见冲突 | 保留两方意见并升级责任人 | 复核存在分歧 |
| 导出失败 | 不生成虚假下载记录，允许重新生成 | 导出失败，未形成护照 |
