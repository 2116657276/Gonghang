# 潮汐·创证匿名访谈提纲

> 文档状态：历史研究分支。本文访谈问题围绕科创双证据材料，当前小微借贷周期需另行设计访谈。

## 一、开场说明

本访谈用于竞赛原型研究，关注科创小微企业如何组织研发进展、产品版本、订单履约和融资准备材料。访谈只记录匿名结论，不收集企业名称、账户、真实合同、客户名单、内部审批规则或其他保密信息。参与者可跳过任何问题，并可决定其观点是否允许匿名引用。

## 二、企业侧问题

1. 需要外部解释研发进展时，哪些材料最难整理或相互对应？
2. 技术、产品、订单和财务材料通常由哪些角色分别管理？
3. 产品版本、交付、验收和回款状态最容易在哪里出现不一致？
4. 在资金需求出现前，企业何时才会开始准备材料？为什么？
5. 哪些信息愿意在明确用途和期限下分享，哪些信息必须保留？

## 三、银行或服务人员问题

1. 初步理解一家科创小微企业时，哪些材料关系最耗费核对时间？
2. 来源、状态、冲突和人工复核怎样呈现才便于继续尽调？
3. 哪些自动化表述会造成“系统替代审批”的误解？
4. 资金区间与材料就绪区间分开表达是否有帮助？还缺什么依据？
5. 证据护照应怎样脱敏，才能兼顾可用性和商业秘密保护？

## 四、禁止记录

不得记录真实客户身份、完整订单号、精确账户和流水、内部风控阈值、接口密钥、未公开技术细节或未经授权的文件。访谈结论必须标注日期、匿名角色和引用许可范围。
