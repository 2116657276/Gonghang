## 使用前提

本模板只记录经同意、不可逆脱敏后的业务结论。原始合同、聊天记录、流水、证件、地址、真实企业名称和联系人信息不得保存到项目目录。无法安全脱敏时，不收集该案例，改用原型假设。

## 案例登记

| 字段 | 填写规则 |
| --- | --- |
| caseId | 使用 CASE-ANON-XXX，不使用真实企业或客户编号。 |
| 来源等级 | ANONYMIZED_CASE 或 PROTOTYPE_ASSUMPTION。 |
| 可公开范围 | 内部设计、匿名竞赛引用、仅统计结论三选一。 |
| 行业分类 | 只写到不可反向识别的行业层级。 |
| 周转用途类别 | 采购、工资、结算等分类，不写真实项目名。 |
| 参考日与警戒线 | 使用日期区间或相对天数；确认不与真实身份信息组合。 |
| 回款节点 | 仅记录预计区间、证据状态、覆盖区间与材料类型。 |
| 风险缓冲节点 | 仅记录材料/安排类别、预计就绪区间、证据状态与责任角色。 |
| 历史处理动作 | 只记录补证、沟通、人工复核等通用动作。 |
| 可支撑结论 | 只写该案例可验证的时间线或体验问题。 |
| 不能支撑的结论 | 写明不可泛化、不可证明效果的边界。 |

## 脱敏检查清单

- [ ] 未包含真实企业名称、统一社会信用代码、联系人、电话、地址或账户。
- [ ] 未包含合同号、票据号、原始金额、证件、影像或可识别截图。
- [ ] 日期和行业组合不能由项目团队以外人员反向识别。
- [ ] 受访者已明确可使用的范围，或内容已降级为原型假设。
- [ ] 案例结论没有被夸大为系统已部署后的效果。
