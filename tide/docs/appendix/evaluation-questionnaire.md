# 潮汐·创证原型评估问卷

> 文档状态：历史研究分支。本文问卷评价科创双证据原型，不代表当前小微借贷周期的测试问卷。

## 一、测试声明

案例和数据均为模拟或授权脱敏材料，系统不代表真实银行系统，不提供授信、审批或技术价值判断。问卷不收集姓名、企业名称、账户、真实合同或内部规则。

## 二、理解度问题

1. 请指出一项已核验事实和一项仍待核验事实。
2. 研发里程碑链与订单兑现链分别回答什么问题？
3. 资金时钟和就绪时钟的依据是什么？它们是否代表保证到账或保证审批？
4. 当前最关键的材料缺口或冲突是什么？由谁处理？
5. 你能否从证据节点返回材料来源位置？

## 三、量表

请按 1—5 分评分，1 表示完全不同意，5 表示完全同意。

| 陈述 | 分值 |
| --- | --- |
| 我能区分候选事实与已核验事实。 | 1—5 |
| 我能理解两条证据链各自的作用。 | 1—5 |
| 我能理解两个时间区间而不把它们当作承诺。 | 1—5 |
| 我能快速找到异常来源和下一步责任人。 | 1—5 |
| 我认为证据护照的共享边界清晰。 | 1—5 |

## 四、记录规则

记录参与者角色类别、完成时间、错误理解、开放意见和测试日期。样本量不足时只报告观察结果，不计算或宣称行业代表性比例。
