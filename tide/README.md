潮汐关注小微企业经营回款、到期还款与融资准备之间的时间错配。目标是帮助企业整理经营周期、资金缺口及材料准备事项，让企业和业务人员有依据地讨论下一步，而非自动承诺授信、续贷或展期。

## 一、现有材料如何使用

[科创双证据研究索引](docs/README.md)包含既有产品、领域、架构和访谈材料。证据来源、缺口协同、时间区间和人工复核方法可以参考；研发里程碑、知识产权和科创案例不是当前必做范围。

现有详细文档仍以科创双证据研究为主题，保留为方法与材料参考，不作为当前方案的替代品。后续应围绕真实经营周期重新确认角色、案例、规则与接口，再形成新的实施基线。

## 二、后续需要补齐

- 匿名需求访谈：借款用途、回款延迟、到期处理及材料准备的实际困难。
- 产品范围：先帮助企业与业务人员整理事实，不替代机构决策。
- 案例与验证：构造经营回款正常、延迟和材料不足的对照情境。

亲属从业背景不等于数据使用授权，不采集未经许可的客户资料或内部业务规则。
