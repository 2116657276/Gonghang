## 二、当前工作边界

当前仓库以行止为第一优先项目，已有 Vue、Fastify、PostgreSQL、worker、Pi 工具、商户善后和结构化页面的本地实现及局部验证。当前按“先完成后端并统一验收，再统一重构前端，最后综合交付”推进；按用户要求暂缓开发，前端冻结。当前模型固定场景、进程中断和授权连续样本已有证据，但官方交易、多场景模型稳定性、备份恢复及完整 P0 仍待验收，历史局部结果不能视为当前版本全部通过。进度见[开发计划](xingzhi/docs/03-engineering/development-plan.md)，证据见[验证记录](xingzhi/docs/04-quality/verification.md)，启动见[本地运行说明](xingzhi/README.md)。潮汐与绿链继续按已有资料维护。

行止首次完成的 MVP／Demo 覆盖全部 P0 基础功能，开发阶段与交付要求统一在开发计划维护；中间里程碑不称为首版完成，后续再深化体验与稳定性。当前已完成 S1 本地模拟、S3 服务端核心路径及 S4 交易工具／事件恢复、T10 复核、变更善后连续链和 1.3／1.4 恢复准备的本地受控核对，并接入对应结构化页面和确认卡片；官方交易、完整多场景模型链、完整验收和首次交付放行仍未完成。

行止旧计划书用于追溯早期构想，不作为当前实施依据。现行工作提案、外部能力证据、已确认决定和实际验证结果分别管理，具体见[文档规范](xingzhi/docs/00-governance/document-conventions.md)。
