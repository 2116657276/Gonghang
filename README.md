## 二、当前工作边界

当前仓库以行止为唯一现行项目，已有 Vue、Fastify、PostgreSQL、worker、Pi 工具、商户善后和结构化页面的本地实现。2026-09-14 后端本轮实现与 55 项定向验收已收口，支付宝沙箱付款、原单退款查询和待付关单核心链已有记录；前端开发者现可按稳定契约进入页面重构与联调。官方特殊场景、多场景模型稳定性、跨端 36 项 P0 和首次交付仍待验收，历史局部结果不能视为当前版本全部通过。进度见[开发计划](xingzhi/docs/03-engineering/development-plan.md)，证据见[验证记录](xingzhi/docs/04-quality/verification.md)，启动见[本地运行说明](xingzhi/README.md)。

行止首次完成的 MVP／Demo 覆盖全部 P0 基础功能，开发阶段与交付要求统一在开发计划维护；中间里程碑不称为首版完成，后续再深化体验与稳定性。当前已完成 S1 本地模拟、S3 服务端核心路径及 S4 交易工具／事件恢复、T10 复核、变更善后连续链、1.3／1.4 恢复准备和首批官方沙箱核心交易的受控核对，并保留对应结构化页面和确认卡片；官方特殊场景、完整多场景模型链、跨端验收和首次交付放行仍未完成。

行止旧计划书用于追溯早期构想，不作为当前实施依据。现行工作提案、外部能力证据、已确认决定和实际验证结果分别管理，具体见[文档规范](xingzhi/docs/00-governance/document-conventions.md)。
