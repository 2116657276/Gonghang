## 二、当前工作边界

当前仓库已完成既有资料整合，并建立行止开发文档体系。行止已确定 Vue 3、Fastify 与 PostgreSQL 的本地 P0 技术基线，以及从购买开始的完整付款退款闭环；方案确认不代表已经实现。潮汐回归原版小微借贷周期，科创资料保留为旧研究；绿链保持现有方案。当前尚未编写应用代码、测试脚本或部署配置。实施、支付测试、账号授权、签约和真实资金操作须另行确认。

行止旧计划书用于追溯早期构想，不作为当前实施依据。现行工作提案、外部能力证据、已确认决定和实际验证结果分别管理，具体见[文档规范](xingzhi/docs/00-governance/document-conventions.md)。
