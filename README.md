## 二、当前工作边界

当前仓库已完成既有资料整合，并建立行止开发文档体系。行止已确定 Vue 3、Fastify 与 PostgreSQL 的本地 P0 技术基线，并完成 S0、S1 的本地业务基础：响应式网页、服务端会话、计划与预算、暂停、结构化变更、持久化任务和明确标识的模拟适配器。S3 已完成商户规则、取消队列、固定退款批次、受控人工复核与本地 worker 的服务端基础闭环，并把规则预设、取消处理、退款批次、人工任务及消费者善后事实接入结构化页面；费用退款、两笔分批退款及审核行迹导出的本机 JSON／HTML 路径已作定向核对。S2 已填入本机沙箱参数并完成一次只读查单连通性核验，尚未执行官方付款、退款、关单或通知联调。2026-09-08 的环境隔离、任务结果事务、渠道任务及显式复核已有历史验证；截至 2026-09-12，当前工作区的 `pnpm test:targeted` 47 项全部通过，并通过 `pnpm typecheck` 与 `pnpm build`。Pi 0.85.1 已安装，本地工具循环和人民币 100 元共享费用账本通过测试。真实 DeepSeek 已完成只读／方案联调和局部执行评测，人民币预算直接按官方费率计算，无需汇率；API-24、四个只读工具、T04／T08 方案工具、T05／T06／T07／T09、事件恢复、T10 普通消息复核和对应页面衔接已接入并完成本地受控核对。官方支付、真实模型完整连续链、备份恢复、完整 P0 验收和首次交付放行仍须另行完成。运行入口见[行止本地运行说明](xingzhi/README.md)。潮汐回归原版小微借贷周期，科创资料保留为旧研究；绿链保持现有方案。官方支付、账号授权、签约和真实资金操作仍须另行确认。

行止首次完成的 MVP／Demo 覆盖全部 P0 基础功能，开发阶段与交付要求统一在开发计划维护；中间里程碑不称为首版完成，后续再深化体验与稳定性。当前已完成 S1 本地模拟、S3 服务端核心路径及 S4 交易工具／事件恢复、T10 复核和变更善后连续链的本地受控核对，并接入对应结构化页面和确认卡片；官方交易、真实模型完整连续链、备份恢复、完整验收和首次交付放行仍未完成。

行止旧计划书用于追溯早期构想，不作为当前实施依据。现行工作提案、外部能力证据、已确认决定和实际验证结果分别管理，具体见[文档规范](xingzhi/docs/00-governance/document-conventions.md)。
